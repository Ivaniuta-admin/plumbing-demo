# АкваМастер — лендинг сервісу сантехніків із заявками в Telegram

Демо-сайт сантехнічної компанії: клієнт за кілька секунд обирає проблему, залишає заявку з фото або дзвонить, а власник одразу отримує заявку в Telegram.

**Демо:** [ivaniuta-admin.github.io/plumbing-demo](https://ivaniuta-admin.github.io/plumbing-demo/)

> Компанія, ціни й контакти вигадані. Сайт зроблено як демо для замовника.

## Можливості

- Перший екран з пропозицією, кнопками заявки й дзвінка
- Швидкий вибір проблеми (засор, протікання, змішувач, бойлер, унітаз) одразу підставляє її у форму
- Послуги з цінами «від», аварійний виклик, етапи роботи, зона виїзду, FAQ
- Форма заявки з фото; заявка приходить у Telegram через Cloudflare Worker, тож токен бота не потрапляє в код сайту
- На телефоні закріплена нижня панель «Подзвонити / Заявка / Telegram / WhatsApp»
- Адаптивна верстка (телефон, планшет, десктоп) і базова SEO-розмітка schema.org для локального пошуку

## Як працює відправка заявки

1. Форма надсилає дані на Cloudflare Worker.
2. Воркер форматує повідомлення й надсилає його через Telegram Bot API (`sendMessage` або `sendPhoto`, якщо додано фото).
3. Токен бота й chat ID зберігаються в секретах Cloudflare, не в репозиторії.
